# 《没有剧透的中国》第九、十章 V1.1 叙事节奏实验说明

> 阅读者试读材料，未获作者确认前不替换原正式 V1.0 正文、不改大纲与人物设定。

## 目的

针对作者四个反馈中的文学层问题进行一次**完整章节而非局部修句**的对照实验：
- 降低对话的即时问答和句句有效性，让一些话没有当场答案；
- 不再让每一个场景连续遇到大小障碍、紧接着解决、随即证明人物成长；
- 保持接力群像，但延长镜头停留时间，降低章节中的独立视角切换；
- 不订立“一章至多几个困难”的机械数量标准，逐章检查总体阅读疲劳。

## 对照读法

阅读原 V1.0 第9章及其 V1.1 后，比较：
1. 主角在技术工作中的普通重复、一次真实返工和给小梅写信能否提供连续性；
2. 周玲和陈国强相识、交往、选择，有没有变成“好条件对象”刻意对打“真正懂她的对象”；
3. 小梅与周启是否真像在一起度过普通的一个下午，而不是每十分钟发生一个精心设计的小插曲；
4. 已有的“买票却忘带”“自行车掉链”等小戏剧在 V1.1 不再同时出现：电影票确实由小梅本人购买、持有，结束后仍由她保存。

阅读第10章时比较：
1. 原第9章刘建军第一次请本地青年小卢短时帮忙的事件，移到第10章开头，作为出远门前自然整理摊位的背景；这是一项局部章节编排实验，不等于未经批准更改全书锁定大纲；
2. 去广州不再连串上演问路扑空、不同型号、额外包材、少一箱、托运分歧等不同困难。保留一件会真正改变采购行为的权衡：好看的新货要不要冒险整箱进；把其余交易/托运表现为普通而略费精力的现实工作；
3. 刘建军仍善于识别新货商机，王东会记账、对规格，但两人互相等、互相不立即回复，不把选择写成一场漂亮的当场辩论；
4. 保留何老板渐渐记住王东的名字、让他独立处理托运、建军开始让王东设计下一趟进货路径三项确定节点。不提前放大为1992年的代理权矛盾。

## 本次实验的结构边界

- 第9章实验稿保留周启首次正式署名并返工、周玲认识并选择陈国强、小梅的电影约会、夜校和母亲留饭。独立视角为**周启、周玲、小梅**，周启占连续前两场。
- 第10章实验稿用**刘建军→王东**两段接力，整体连续经历出门准备、火车、南下寻货、办运回城。章节内部三处大场景，未强行把每个业务细节写成一场危机。
- 由于第9章不再设置刘建军的独立帮手场，小卢这一原有故事节点前移到第10章第一段业务准备；后续第11章《婚礼》、1986—87稳定正式雇佣节点均不动。
- 第9章、10章原 `manuscript-v1.0.md` 保持有效的正式版本。此次实验稿分别位于 `chapters/ch09/experiments/manuscript-v1.1-natural-rhythm.md` 和 `chapters/ch10/experiments/manuscript-v1.1-natural-rhythm.md`；同一次阅读比较时勿将原第9章单独和实验第10章混合。

## 写后自检：不当成既定新规

重新读实验稿时，只问四件事：有没有某个角色忙于“演示成长”；人物日常是否只剩事件过场；看似平淡的段落是否仍然让人愿意看下去；减去冲突是否把小说改成了流水账。

这一次新稿减少了对话和无谓障碍，**存在新的风险：写得过于平缓，情绪张力不足**。应由作者通读比较后确定，下一轮可能选择 V1.0 与 V1.1 的中间方案，而不是自动宣布新写法优于旧稿。
