# 《没有剧透的中国》数字书基础排版标准 V2.0

> 状态：**APPROVED TECHNICAL BASELINE**
>
> 生效：2026-09-24 内容重构后
>
> 本文件只定义数字书的页面与分页技术。内容策略以 `PROJECT.md`、`WORKFLOW.md`、`book/narrative-rules.md` 为准。

## 1. 当前默认版式

正式正文默认采用：

**单页数字书 + 纯文本长篇叙事版式**

旧版本的“正文 + 时代旁注 / 历史照片 / 编辑视觉”不再是默认正文结构。

历史照片、旁注、右侧视觉栏等技术能力继续保留，但只有在 CONTENT LOCKED 后经过明确判断才启用。

## 2. 基准书页

| 项目 | 标准值 |
|---|---:|
| 逻辑书页 | 820 × 1080 |
| 左右正文边距 | 76px |
| 页眉位置 | top 44px |
| 正文版心顶部 | 94px |
| 正文版心底部 | 距页底 76px |
| 页脚位置 | bottom 24px |
| 正文字号 | 约 17.3px |
| 正文行距 | 约 1.84–1.88 |

这些参数是当前默认技术母版。若全书统一调整，应同步共享CSS/JS和样页。

## 3. 扉页

- 章节标题优先保持清晰、克制；
- 扉页允许大面积留白；
- 扉页不参与普通正文首行线/末行线规则；
- 旧 Demo 的标题和具体字号不再作为正式章节内容约束。

## 4. 场景起始页

只有真正换场景时才显示场景标题。

节奏：
1. 页眉；
2. 上方呼吸空间；
3. 场景标题；
4. 标题下方适度留白；
5. 正文；
6. 正文仍尽量排到统一末行区域。

禁止：
- 为了形式感频繁造小标题；
- 因为标题存在就让页面底部留下大块无意义空白。

## 5. 普通连续正文页

- 从统一正文版心顶部开始；
- 除场景真实结束、章节结束或主动情绪停顿外，正文尽量接近统一末行线；
- 优先在自然段边界分页；
- 不按固定字数机械切页；
- 不为了视觉元素提前断页。

目标：读者首先感觉自己在读一本小说，而不是一组设计页面。

## 6. 分页方法

正式章节采用：
**连续内容流 → 浏览器真实测量 → 自动分页 → 人工阅读校验**

步骤：
1. 按故事顺序形成连续正文；
2. 浏览器测量真实渲染高度；
3. 未溢出则继续加入；
4. 溢出时将最后一个完整段落移到下一页；
5. 检查上一页是否异常过空；
6. 场景起始页应用标题规则；
7. 普通页应用固定首行线与末行线；
8. 输出整章逐页截图做视觉复核。

禁止为了“看起来差不多”手工随意切页。

## 7. 正文标题规则

只在真正换场景时出现标题。

同一场景连续分页：
- 不重复大标题；
- 保留轻量页眉；
- 正文直接延续。

## 8. 页面密度验收

普通正文页检查：
- 顶部是否无原因留白；
- 底部是否异常欠填充；
- 是否溢出页脚；
- 是否出现孤立短段造成奇怪空洞；
- 是否因分页算法破坏对话节奏。

章节最后一页允许保留更多自然留白。

## 9. 可选视觉页型

以下能力从“默认母版”降级为**备用能力**：
- 时代旁注；
- 正文历史照片；
- 正文内编辑视觉；
- 右侧视觉栏；
- 多图视觉组；
- AI场景复原。

启用条件：
1. 正文已 CONTENT LOCKED；
2. 去掉视觉后确实损害理解/感受/史料证据；
3. 不会打断关键人物情绪；
4. 经过单独页面审阅。

旧实现仍可参考：
- `web/shared/css/editorial-layout.css`
- `web/shared/js/editorial-layout.js`
- `design/layout-lab/index.html`

其中带旁注/历史照片/编辑视觉的样页属于**技术样例，不是内容模板**。

## 10. 历史照片与AI图

若后续确实启用：
- 历史照片保留来源、年份、权利状态；
- 不把史料人物当成虚构角色；
- AI必须明确标注复原属性；
- 不在公共规范中预设统一3:2或4:5；画幅由实际用途决定；
- 图片必须在加载完成后重新执行最终分页。

## 11. 自动与人工QA

工程阶段至少继续执行：

```bash
python scripts/check-local-assets.py
python scripts/render-layout-review.py web/chXX/index.html
```

必须人工复核：
- 溢出；
- 异常顶部/底部留白；
- 孤页；
- 连续短对白被机械拆散；
- 场景标题位置；
- 页码连续；
- 整章阅读节奏。

## 12. 变更原则

本标准是**技术母版**，不是内容结构。

人物、剧情、叙事方式发生变化时，不应反过来迁就旧视觉页型。

如果以后正式启用新的资料层/视觉层，再增加独立规范，而不是污染主叙事母版。
