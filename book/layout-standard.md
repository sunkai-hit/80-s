# 《没有剧透的中国》数字书基础排版标准 V1.0

> 状态：**APPROVED BASELINE / 已确认母版**
>
> 生效日期：2026-09-24
>
> 本规范服从根目录 `WORKFLOW.md`。所有章节的网页排版默认按本规范执行。
>
> 经过验证的参考实现：`design/layout-lab/index.html`。

---

## 1. 版式定位

全书采用：

**单页数字书 + 纪实小说版式**

核心比例：

**约 80% 小说阅读逻辑 + 20% 史料 / 时代解释 / 编辑视觉。**

正文始终是主角。视觉材料应“长在叙事里”，而不是频繁把读者从正文带到独立的“时代XX页面”。

---

## 2. 基准书页

当前锁定参数：

| 项目 | 标准值 |
|---|---:|
| 逻辑书页 | 820 × 1080 |
| 左右正文边距 | 76px |
| 页眉位置 | top 44px |
| 正文版心顶部 | 94px |
| 正文版心底部 | 距页底 76px |
| 页脚位置 | bottom 24px |
| 正文字号 | 约 17.3px |
| 正文行距 | 约 1.84–1.88 |
| 旁注栏宽度 | 约 205px |
| 正文内图片宽度 | 约 42%–44% |

这些参数是全书默认母版。后续章节不得自行改变；如需调整，应作为“全书级样式变更”统一修改。

---

## 3. 扉页

- 章节标题优先保持单行。
- 第一章 `如果你在1985年二十岁` 固定单行显示。
- 当前基准字号约 48px。
- 扉页允许大面积留白，正文页不沿用这种留白逻辑。
- 扉页属于特殊页面，不参与普通正文“首行线 / 末行线”规则。

---

## 4. 场景起始页

只有真正换场景时才出现场景标题。

### 固定节奏
1. 页眉；
2. 明显的上方呼吸空间；
3. 场景标题；
4. **标题下方再保留与标题上方视觉上接近的留白**；
5. 正文开始；
6. 正文继续排到统一末行区域。

### 禁止
- 标题贴近页眉；
- 标题下方立即接正文；
- 因为标题存在，就让正文底部留下大块空白。

场景起始页唯一被允许的主动留白，是**标题周围的呼吸空间**。

---

## 5. 普通连续正文页

这是全书最重要的基础页型。

### 首行线
普通连续正文页从统一正文版心顶部直接开始。

### 末行线
除以下情况外，正文必须排到统一末行区域：
- 场景在本页真实结束；
- 章节在本页真实结束；
- 明确设计的情绪停顿页。

普通页面不得为了“高级感”在底部留下大块空白。

### 分页目标
- 以浏览器实际渲染高度分页，不按固定字数分页。
- 在不溢出的前提下，优先让最后一行接近统一末行线。
- 普通正文页建议底部剩余空间不超过约 **1–1.5 行正文高度**。
- 优先在自然段边界分页。
- 不为了配图、旁注或“时代XX”而提前断页。

---

## 6. 小标题规则

正文中只有“真正换场景”的标题属于版式标题。

以下类型的文字通常不再作为页面标题：
- “一万元”
- “TOEFL”
- “美元”
- “地图外面”
- “机会第一次有了形状”
- 类似的段落概括语

同一场景跨页后：
- 不重复大标题；
- 只保留轻量页眉；
- 正文直接续写。

---

## 7. 时代内容：不再存在“独立时代XX页”

“时代翻译 / 时代影像 / 时代证据 / 时代尺度 / 编辑视觉”默认都不是独立页型。

它们应作为以下三类元素融入正文：

### A. 时代旁注
用于解释制度、规则和当时人默认知道、今天读者未必理解的背景。

规则：
- 默认位于页面**右下区域**；
- 旁注顶部有一条短横线，**横线只属于旁注本身**；
- 旁注上方正文保持全宽通栏；
- 只有进入旁注实际高度范围后，正文才绕排到旁注左侧；
- 旁注底部与正文版心底部对齐；
- 同页多个旁注时，从底部向上堆叠，空白留在右栏上方；
- 不允许旁注导致正文整体提前缩成左栏；
- 不允许为了贴底旁注而在正文中制造整页横向空白。

### B. 历史照片 / 实物史料
规则：
- 直接嵌入正文；
- 常用宽度约 42%–44%；
- 文字自然绕排；
- 保留年份、来源、署名 / 权利、用途说明；
- 不暗示图片人物就是虚构角色。

### C. 编辑插图 / 场景复原图
规则：
- 与历史照片使用类似的正文嵌入方式；
- 必须标明“场景复原图 / 编辑复原图 / 编辑视觉”；
- 不伪装成真实历史照片；
- 默认不单独占页。

### 例外
只有章节视觉高潮、明确情绪停顿、章节收束等极少数情况，才允许近全页视觉。必须是主动设计，而不是默认模板。

---

## 8. 旁注的标准实现

禁止再使用以下方式：
- 把页面硬切成“上半页 / 下半页”两个区块；
- 从页面顶部就预留一个右栏；
- 给右栏加超大 `margin-top` 把旁注硬推到底；
- 为旁注制造横跨全页的大块空白。

标准实现：

1. 旁注本体绝对定位或等价方式固定到右下；
2. 使用同高度的 wrap shape / shape-outside 只在旁注真实纵向区域保留右侧空间；
3. 旁注以上正文保持 100% 宽度；
4. 进入旁注纵向区域后，正文才自动绕到左侧；
5. 旁注高度变化时，应自动重新计算环绕起点，不使用魔法数字。

共享实现参考：
- `web/shared/css/editorial-layout.css`
- `web/shared/js/editorial-layout.js`

---

## 9. 正文内图片标准

历史照片和编辑插图默认：
- 宽度：42%–44%；
- 浮动位置根据叙事决定，常用右浮；
- 图片与正文间距约 26–30px；
- 图注使用较小无衬线字体；
- 图片不应造成正文顶部或底部的大块空白；
- 图片所在页仍然遵守普通正文页的末行规则。

---

## 10. 行内重点词

行内重点词可以加粗，但需要与前后正文保留轻微呼吸。

标准 class：

```css
.keyword {
  font-weight: 700;
  margin: 0 .16em;
  letter-spacing: .015em;
}
```

避免：

`工作证意味着……`

视觉上紧贴。

应呈现为：

`工作证  意味着……`

但只保留非常轻微的视觉距离，不插入明显空格。

---

## 11. 页面密度验收

每个普通正文页必须同时检查：

### A. 顶部
- 第一行是否从统一首行线开始；
- 是否出现无原因的大块顶部空白。

### B. 底部
- 最后一行是否接近统一末行线；
- 是否存在超过约 1–1.5 行高度的无原因留白。

### C. 溢出
- 任何正文、旁注、图注不得进入页脚区域；
- 不得依赖 `overflow:hidden` 把超出内容“藏掉”。

### D. 图片 / 旁注
- 是否只是影响自己实际占用的区域；
- 是否错误地让整页正文提前缩窄；
- 是否产生大块横向空白。

---

## 12. 分页方法

正式章节采用“内容流 → 浏览器测量 → 分页”逻辑：

1. 先按故事顺序形成连续正文流；
2. 加入需要的旁注 / 图片节点；
3. 使用真实浏览器渲染高度判断当前页是否还能容纳下一段；
4. 未溢出则继续加入；
5. 溢出则将最后一个完整段落移到下一页；
6. 检查上一页底部是否明显过空；
7. 若过空，尝试调整前后段落或视觉节点位置；
8. 场景开始页使用独立标题留白规则；
9. 普通连续页使用固定首行线与末行线。

**禁止手工为了“看起来差不多”随意切页。**

## 13. 六种基准样页

`design/layout-lab/index.html` 是当前经过用户审阅的参考母版，包含：

1. 扉页
2. 场景起始页
3. 普通连续正文页
4. 正文 + 右下时代旁注
5. 正文 + 历史照片
6. 正文 + 编辑插图

以后出现排版争议，优先与这六种页型对照，而不是重新凭感觉设计。

## 14. 变更原则

这是全书级版式标准。

后续章节：
- 默认直接复用；
- 不逐章重新设计；
- 不因为某一页特殊情况就改公共规则。

只有出现以下情况才修改本标准：
- 多章验证后发现公共问题；
- 新页型确实无法用现有六种基础页型表达；
- 用户明确要求全书级视觉调整。

修改标准后，必须同步：
- `WORKFLOW.md`
- `book/visual-guide.md`
- 共享 CSS / JS
- 必要时更新 `design/layout-lab/`

## 15. V1.1 补充：多配图与旁注避让

### 同页多个配图
同一叙事页确有两个相互关联的视觉时，禁止让两个独立 float 自行竞争版面。

标准做法：
- 两张相关图片合并为一个 `inline-visual-pair`；
- 使用双列并排；
- 整组视为一个编辑视觉节点；
- 正文在组块之前/之后正常通栏；
- 如果整组放不下，再整体顺延，不拆出“图片孤页”。

### 时代旁注
旁注环绕区必须使用**未受页面缩放 transform 影响的 CSS 布局高度**计算。

实现要求：
- 使用 `offsetHeight` / `clientHeight`；
- 禁止拿 `getBoundingClientRect().height` 与未缩放的 `clientHeight` 混算；
- 环绕区域应比旁注真实高度向上多预留约 10–14px 安全距离；
- QA 必须检查正文行框是否与旁注矩形发生真实交叠。

## 16. V1.2 补充：统一右侧视觉栏

为保证整本书的图文语言一致，正文内视觉统一采用“右侧视觉栏”：

- **1 张图**：右侧单图，宽度约 42%–43%，正文自然绕排；
- **2–3 张相关图**：合并为一个右侧纵向视觉组，沿用与单图相同的宽度与位置；
- **4 张及以上**：禁止在同一页硬塞，按叙事位置拆到后续页面；
- 多图不再横向铺满正文宽度，不做杂志式“图墙”；
- 图片外不增加卡片底色、色块底板、描边或阴影；
- 保留图片本身与小号图注即可；
- 图片本身若自带纸张/底色，保持素材原貌，不额外覆盖。

这样单图、双图、三图的阅读关系保持一致：正文是主体，视觉始终作为右侧证据/补充进入叙事。

## 17. V1.3 补充：AI 视觉画幅、图注与发布前视觉 QA

### AI / 编辑复原图画幅
进入正文右侧视觉栏的 AI / image2 资产，默认在生成阶段直接制作成 **3:2 横幅**。

原因：
- 本书主要历史照片以横向约 3:2 为主；
- AI 图如果使用 3:4 / 4:5 竖幅，会迫使前端用底板、留白或异常裁切去迁就素材；
- 正确流程是“素材先适配出版版式”，而不是让前端替不合适的画幅补救。

要求：
- AI 图源文件自身就是横幅构图；
- 不使用外部米色底板、卡片背景、阴影来补比例；
- 不把竖版海报硬塞进正文右栏；
- 数字、制度解释等内容优先放在 HTML 图注 / 旁注，不依赖生成图里的小字。

### 图注统一
所有正文图片（历史照片 / 实物 / AI 编辑视觉）的图注统一：
- 10.5px；
- 行高 1.55；
- 上边距 7px；
- 同一颜色与无衬线字体；
- 不再因“单图 / 多图 / 历史图 / AI 图”使用不同字号。

### 发布前视觉 QA
正式发布前不能只做 overflow 检查，还要做视觉版面检查：
- 普通正文页异常欠填充；
- 图片孤页；
- 图片组起始位置过低；
- 连续短句把图片顶到页面中部；
- 旁注与正文交叠；
- 视觉节点上方 / 下方出现不符合叙事节奏的大块空白。

自动 DOM QA 负责发现几何异常；
同时必须输出整章逐页截图进行人工视觉复核。
