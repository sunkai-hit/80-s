# Web Book 视觉与 HTML 规范 V1.0

## 1. 产品形态

不是 PPT，不是双页电子书，也不是普通公众号文章。

目标是：

**长文阅读 + 编辑型杂志 + 纪录片网页**

正文始终是主角。

## 2. 页面基本结构

纵向连续阅读。

建议三种内容宽度自然切换：

- 窄：纯正文，约 720—820px
- 中：正文 + 时代翻译/史料说明，约 900—1000px
- 宽：高质量图片、史料或信息图，约 1100—1200px

不要平均分布视觉模块。

允许连续多屏纯文字，到关键节点再使用高质量视觉内容。

## 3. 文字以外的六类内容

1. 场景复原图
2. 时代翻译
3. 原始史料
4. 实物特写
5. 信息图
6. 时间/尺度卡

每一项必须解决一个明确的阅读问题。

## 4. 视觉来源优先级

### 第一优先
真实历史照片、博物馆资料、老报刊、老广告、票证、文件扫描件。

### 第二优先
经过编辑设计的真实史料组合。

### 第三优先
AI 场景复原图。

AI 图必须标注：

> 场景复原图，根据相关史料与章节内容制作。

### 第四优先
独立制作的信息图。

## 5. HTML/CSS 可以做什么

可以：

- 排版
- 留白
- 字号层级
- 简单边框与背景
- 轻量时间轴
- 图片放大
- 展开时代翻译
- 史料说明

不可以用 HTML/CSS 假装绘制：

- 人物
- 自行车等复杂物件
- 历史生活场景
- 复杂地图
- 复杂信息图

复杂视觉应先作为独立 SVG/PNG/WebP 资产完成，再嵌入 HTML。

## 6. 风格

第一章基调：

**温暖、真实、克制、轻微年代质感。**

避免：

- 满页泛黄滤镜
- 过度怀旧
- 科技官网风
- 卡片堆叠
- 炫技动画
- 视觉素材的“80年代符号堆砌”

## 7. 视觉比例

正文约 75%—80%。

视觉内容约 20%—25%。

图片数量不求多，关键节点使用高质量大图。
