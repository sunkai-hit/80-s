# Web Book 视觉与 HTML 规范 V2.0

> 本规范服从根目录 [WORKFLOW.md](../WORKFLOW.md)。如有冲突，以 WORKFLOW.md 为准。

## 1. 产品形态

默认形态：

**单页数字书 + 纪实小说版式**

不是：
- 横版双页书册；
- 无限下滚长网页；
- PPT；
- 公众号文章。

目标是让读者产生“一页一页读书”的感觉，同时保留数字媒介的轻交互能力。

正文始终是主角。

---

## 2. 书页结构

### 桌面端
- 一屏只显示一张逻辑书页；
- 页面有明确纸张边界、页眉、页码和外部背景；
- 页面整体随视口缩放；
- 页内禁止纵向滚动；
- 滚轮、方向键、PageUp/PageDown、空格用于翻页。

### 移动端
- 保持单页逻辑；
- 以左右滑动为主要翻页方式；
- 不退化成无限长文章。

### 当前基准尺寸
第一章采用 820 × 1080 逻辑书页。后续章节原则上沿用共享书页系统，除非全书统一调整。

---

## 3. 正文页规则

- 正文页以文字为主；
- 普通连续页从统一首行线开始，排到统一末行区域；
- 场景起始页只在场景标题周围保留主动留白，标题后正文仍排到统一末行区域；
- 历史照片、时代旁注、编辑视觉默认融入正文，而不是独立成页；
- 同一个场景允许跨多页连续阅读；
- 连续页不重复正文大标题；
- 完整版式规则见 `book/layout-standard.md`。

### 标题规则

只在真正换场景时显示大标题。

同一场景的后续分页：
- 隐藏重复正文标题；
- 保留轻量页眉定位；
- 正文直接延续。

目的：避免“每页都像 PPT 有一个标题”。

---

## 4. 文字以外的六类内容

1. 真实历史照片
2. 原始史料 / 文件 / 票证
3. 实物特写
4. 时代翻译
5. 编辑型信息视觉 / 时间尺度页
6. AI / image2 场景复原

视觉内容默认作为“叙事中的证据与解释”嵌入正文，不再默认独立成页。

常用形式：
- 右下时代旁注；
- 正文内历史照片 / 实物史料；
- 正文内编辑插图 / 场景复原图。

每一项仍必须解决一个明确阅读问题。

---

## 5. 视觉来源优先级

### 第一优先
真实历史照片、档案、老报刊、老广告、票证、文件扫描件、博物馆实物。

### 第二优先
经过编辑设计的真实史料组合。

### 第三优先
AI / image2 场景复原或编辑复原。

### 第四优先
独立制作的信息视觉。

原则：

> 猎奇负责把读者带进来，史料负责把读者留下来。

AI 图不得伪装成真实历史照片。

---

## 6. image2 / 编辑视觉规则

复杂视觉不再用 HTML/CSS 或程序式 SVG 临时拼出来。

适合 image2：
- 场景复原；
- 道具复原；
- 时代概念解释；
- 信息尺度视觉；
- 章节收束型视觉。

必须避免：
- 企业 PPT 风；
- 圆角框 + 箭头 + 节点；
- 程序员流程图感；
- 为了填空而制作的低质量插画；
- 80年代符号堆砌。

统一标注可使用：
- 场景复原图
- 编辑复原图
- 编辑视觉

并在图注中说明依据与非史料原件属性。

---

## 7. HTML/CSS 的职责

### 可以
- 书页排版
- 留白
- 字号层级
- 纸张边界与背景
- 页眉 / 页码
- 轻量翻页
- 图片查看
- 时代翻译展开
- 史料说明

### 不可以
- 绘制人物
- 绘制复杂物件
- 绘制历史生活场景
- 拼复杂地图
- 拼复杂关系图 / 信息图
- 在 HTML 阶段临时创造正文

复杂视觉必须先作为独立图片资产完成，再嵌入 HTML。

---

## 8. 视觉风格

全书基础气质：

**温暖、真实、克制、轻微年代质感。**

避免：
- 满页泛黄滤镜
- 过度怀旧
- 科技官网风
- 卡片堆叠
- 炫技动画
- 视觉素材的“80年代符号堆砌”
- 每页都塞一张图

视觉数量由叙事节奏决定，不按固定页数机械分配。

---

## 9. 历史照片与故事人物的边界

历史照片用于证明“那个时代确实存在这样的城市、服装、物件和公共空间”。

不得：
- 暗示照片人物就是虚构角色；
- 把1988照片写成1985故事现场；
- 用近年代照片替代精确事实而不说明；
- 把博物馆实物说成故事人物实际使用的物件。

页面图注必须说明：
- 年份；
- 来源；
- 权利状态 / 署名；
- 是否为近年代参考。

---

## 10. 图片本地化规则

所有进入正式 HTML 的图片必须先本地归档到仓库。

### 历史图片
```
assets/chXX/historical/
```

### image2 / AI / 编辑视觉
```
assets/chXX/generated/
```

HTML 中的 `<img src>` 只允许引用项目内相对路径，不允许运行时直接引用：
- Wikimedia
- 博物馆
- 新闻媒体
- 图床
- 其他外部图片地址

原始 URL、作者、许可继续保存在：
- `assets/chXX/historical/README.md`
- `sources/copyright.md`

本地化不会改变原始版权属性。

---

## 11. HTML 完成前检查

至少执行：

```bash
python scripts/check-local-assets.py
```

并确认：
- 远程图片引用 = 0
- 缺失本地图片 = 0
- 正文页大图混排 = 0
- 旧复杂 SVG / HTML 绘图引用 = 0
- 图片图注完整
- AI与真实史料标识清楚
- 单页无纵向溢出
- 页码连续
- 连续正文不重复大标题

未通过以上检查，不标记为 `WEB REVIEW` 或 `FINAL`。

## 12. 已锁定的排版母版

全书正式采用 `book/layout-standard.md` 中的“纪实小说”母版。

核心规则：
- 正文分页不为视觉内容让路，正文阅读密度优先；
- 普通正文页使用固定首行线与末行线；
- 场景标题明显下沉，标题上下形成平衡留白；
- “时代XX”不再作为独立页出现；
- 旁注默认放在右下，横线只属于旁注本身；
- 旁注上方正文保持通栏，只在旁注实际高度范围内绕排；
- 历史照片、实物、编辑视觉默认作为正文内插图；
- 近全页大图仅用于明确的视觉高潮或情绪停顿；
- 行内重点词加粗时保留轻微左右呼吸；
- 禁止用大块空白、硬切上下区块、超大 margin 等方式“凑版”。


## 13. 多个配图与旁注避让

- 同一页出现两个相关视觉时，优先组合成双列视觉组，而不是放两个独立浮动图；
- 双图作为一个整体节点参与分页；
- 不允许为了第二张图生成只有图片、没有正文的页面；
- 时代旁注的正文避让区域按旁注真实未缩放高度计算，并额外预留少量安全距离；
- 任一正文行进入旁注区域都视为排版失败。


## 14. 视觉栏统一规则

正文视觉统一靠右：
- 单图：右浮；
- 双图 / 三图：右侧纵向堆叠，作为一个视觉组；
- 超过三图：拆页，不做横向图墙；
- 图片不加额外背景板、卡片框或阴影；
- 图注直接置于图片下方。
