# Web Book 视觉规范 V3.0

> 状态：**CURRENT**
>
> 2026-09-24 起，视觉策略从“正文 + 时代旁注/历史照片”调整为“正文故事优先，资料层可选”。

## 1. 正式正文默认形态

**单页数字书 + 纯故事阅读。**

默认不在主叙事页面插入：
- 时代旁注；
- 历史知识卡；
- 解释型统计视觉；
- 为证明真实性而出现的历史照片；
- AI复原插图。

这不是永久禁止视觉，而是避免在故事尚未完全成立前用视觉和解释打断阅读。

## 2. 正文页面

保留已经验证过的数字书工程：
- 一屏一张逻辑书页；
- 明确纸张边界；
- 页眉/页码；
- 页内不纵向滚动；
- 键盘/滚轮/触摸翻页；
- 820×1080 当前逻辑页尺寸；
- 浏览器真实渲染高度分页。

正文页以文字为主。
场景起始页才显示场景标题。
连续场景跨页不重复标题。

## 3. 资料与视觉层

只有正文 CONTENT LOCKED 后，才判断是否需要额外资料。

优先放置位置：
1. 书末档案；
2. 章末资料；
3. 电子版主动点击/展开的可选层；
4. 极少数经过验证确实不打断叙事的正文视觉。

主叙事不承担“把所有时代知识解释清楚”的任务。

## 4. 历史照片

历史照片的作用是史料，不是氛围装饰。

如使用：
- 不暗示照片人物就是虚构角色；
- 不把近年代照片伪装为故事现场；
- 记录年份、来源、权利状态；
- 正式HTML使用前必须本地化；
- 默认进入资料层而不是正文流。

## 5. AI / 编辑视觉

仅当真实史料无法解决明确需求时使用。

必须：
- 标明“场景复原图 / 编辑复原图 / 编辑视觉”；
- 不伪装为真实历史现场；
- 不做PPT式框图；
- 不为了填页面空白而生成；
- 画幅在确定实际页面用途后再定，不在公共规范中强制3:2或4:5。

## 6. HTML职责

可以：
- 排版；
- 翻页；
- 文字层级；
- 可选资料展开；
- 已确认图片查看。

不可以：
- 临时创作正文；
- 临时补时代解释；
- 绘制复杂人物/场景/信息图；
- 用卡片系统把小说变成知识网页。

## 7. 旧版视觉资产

旧第一章中的：
- 时代旁注；
- 历史照片；
- 编辑视觉；
- AI复原；
- 右侧视觉栏

全部保留为技术与设计实验资产，但不再是正式章节必须继承的内容结构。

## 8. 本地化与版权

凡进入正式Web Book的外部图片：
- 必须本地化到仓库；
- 必须记录原始来源和权利状态；
- 不允许远程热链；
- UNKNOWN版权不得进入公开正式版本。

## 9. 当前排版关系

`book/layout-standard.md` 中的字体、版心、分页、场景标题、首末行控制仍是有效的技术参考。

其中关于“时代旁注、正文历史图片、右侧视觉栏”的页型视为**备用能力**，不再是默认正文母版。

## 10. 视觉决策的唯一问题

每个视觉出现前只问：

> **去掉它以后，故事是否更难理解、更难感受，或缺少必须的史料证据？**

如果答案是否定，就不加。
