# 《没有剧透的中国》全书场景链与压缩方案 V0.1

> 状态：**SCENE-CHAIN BASELINE / CURRENT STORY DEVELOPMENT**
>
> 来源：`book/master-scene-pool-v0.1.md` 的137个现场场景候选。
>
> 本轮没有新增剧情。全部137个候选均被纳入且仅纳入一次。
>
> **压缩结果：137个现场候选 → 62条场景链。**
>
> 这里的“62条场景链”不等于62个最终场景，也不等于62章。一条场景链可以包含：
> - 一个必须独立呼吸的单核场景；
> - 两三个连续场景；
> - 少数跨数年的同一人物成长链；
> - 大型汇聚事件中的多个有限第三人称场景。
>
> 场景链的作用，是把“场景母表”从137个散点变成未来可以聚合章节的叙事单元。
>
> **重要约束：**
> - 不把周启大学/研究院线压回履历；
> - 不把小梅纽约线压成蒙太奇；
> - 不机械轮换人物；
> - 同一场景仍坚持一个POV；
> - 跨POV的“场景链”必须在实际正文中换场后再换意识。

## 本轮最明确的压缩动作

1. M034“市场那边更便宜”嵌入周玲柜台成长链，不再单独承担大场。
2. M035“小本子”成为建军/王东商业能力链中的关键物件，不必独立成一场。
3. M053“第一次被叫刘老板”作为“第一个帮手”后的身份回声，不单独占大场。
4. M039与M056两个“第一次远途供应链”合并为一次更完整的远途生意事件，避免功能重复。
5. M071“先还谁”嵌入“重新开张”的现金流选择。
6. M078“正式企业”嵌入M077的登记/纸面身份戏。
7. M107“何老板问王东呢”嵌入“空的那张桌子”场景，作为最普通却最刺痛的一句。
8. M130“我也有工作”并入1995“反正周玲在”的冲突起势。

这意味着至少8个原候选已经明确不再需要单独的完整场景边界；更多B化/融合要等试写后决定。

# 七、压缩后的结构观察

## 1. 62条链比137个散点更接近“小说”

137个场景母表解决的是“人生够不够厚”。

62条场景链解决的是“这些人生怎样读起来不散”。

现在已经能看到一种稳定节奏：

**独立生活 → 与旧关系重逢 → 选择产生后果 → 再回独立生活。**

这比此前“只写人物交叉”或“按年份轮流写”都更健康。

## 2. 双主线现在真正贯穿全书

周启不是只在：
高考、婚礼、1992不下海、1995回家时出现。

他的独立链持续经过：
西安宿舍 → 专业挫折 → 车间 → 分配 → 研究院 → 返工 → 机器运行 → 项目责任 → 市场约束 → 不下海 → 管理 → 苏岚。

小梅也不是只在：
等周启、母亲去世、去美国时出现。

她持续经过：
饭店新人 → 工作方法 → 主动放弃培训 → 英语 → 母女关系 → 值夜班 → 医院照护 → 失去生活中心 → 涉外饭店 → 美国申请 → Queens → 培训挫败 → 自己解决 → 自由/孤独 → 是否回国。

两条主线已经能够独立阅读。

## 3. 1988、1990、1992、1995四个年份自然成为“高密度区”

不是因为这些年份历史大事更多，
而是因为人物关系在这些地方发生不可逆变化。

- 1988：建军/王东共同失败；
- 1990：小梅母亲去世、停止等待；
- 1992：建军/王东决裂、周启不下海、小梅选择美国机会；
- 1995：各条人生重新回到周家原点。

这说明“人物驱动时间密度”已经成立。

## 4. 1993—1995场景密度仍然高，但目前不建议继续硬压

后段同时需要完成：
- 小梅纽约生活真正成立；
- 王东独立后重新建立信用；
- 建军成为真正老板；
- 周启承担“不下海”的后果；
- 周玲中年照护负担累积；
- 1995最终汇聚。

如果此时为了章数好看强压，很容易重新把人物独立人生删掉。

因此后半段密度先保留，等章节聚合时再判断。

## 5. 原22章结构正式退出“当前入口”

`book/chapter-structure-v0.1.md` 继续保留为历史中间版本，
但不再作为后续写作结构。

下一版章节必须从这62条场景链重新长出来。

# 八、下一步：从场景链形成“叙事段落”，暂时仍不编号章节

下一轮建议先形成约 **28—36个叙事段落（narrative sequences）**。

一个叙事段落可能包含：
- 1条大型场景链；
- 或2—3条互相增强的场景链。

它应该满足：
1. 有一个明确的阶段性问题；
2. 结束时人物关系/自我认知已发生变化；
3. 有足够强的结束动作，让读者愿意继续；
4. 时间跳跃原则上发生在叙事段落之间；
5. 同一段落可以多POV，但每个场景仍单POV。

等叙事段落成立后，
再判断哪些段落应该单独成章、哪些可以两段合章。

**不先决定全书有多少章。**
