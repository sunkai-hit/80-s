# 一、第一轮合并后的关键判断

## 1. “47个关系场景”问题已经解决

此前最大偏差是：
人物只有彼此相遇时才像在生活。

本表中大量新增场景发生于：
- 西安大学；
- 郑州研究院；
- 国营饭店；
- 夜校；
- 百货商店；
- 正街市场；
- 农村老家；
- 货运站与供应链；
- Queens合租房；
- 纽约酒店和地铁。

人物现在拥有彼此不知道的人生。

## 2. 双主线不靠爱情维系

周启与林小梅的主线场景大量发生在两人不见面的时候。

周启：
大学、工程、研究院、项目管理。

小梅：
饭店、母亲、英语、涉外职业、纽约。

因此两人错过时，损失的不是“一个恋爱结局”，
而是两个已经分别长成的完整人生没能继续并行。

## 3. 1990以后小梅的戏份明显上升是有意的

前半程：
小梅不断“等”，戏剧动作更小。

母亲去世以后：
她开始主动做决定。

因此1990—1995她的现场密度上升，
不是后半段抢戏，
而是人物弧光本身开始加速。

## 4. 建军/王东不再只有三次大冲突

他们现在有：
- 市场与跑货学习；
- 信用；
- 帮工/雇人；
- 供应链；
- 农村与城市身份；
- 1988失败；
- 重建；
- 纸面身份；
- 独立经营；
- 成功后的不同代价。

1992决裂因此有十多年生活积累。

## 5. 周玲不再只负责“家庭真相”

她有独立职业成长：
柜台 → 成人学习 → 盘点能力 → 统计/内勤。

所以1995她要求哥哥承担更多，
不是因为她“本来就在家”，
而是她自己的生活长期被默认为可以挪动。

# 二、下一轮压缩原则

下一轮不再新增场景，开始压缩。

重点检查以下类型：

1. **同一地点、同一时间跨度、同一人物连续发生的S/A是否可形成一个长场景**
   - 例如“营业执照 + 第一天摆摊”可能合并；
   - “股份 + 风险太大 + 已经签了”应形成一组连续戏，但未必减少场景切点。

2. **功能重复**
   - 同一个人物连续两次只证明“能力变强”，必须删一场或改变功能。

3. **双主线节奏**
   - 任何超过较长篇幅没有周启或小梅的段落，都要判断是否必要；
   - 但不机械轮换。

4. **生活世界密度**
   - 不能为了压缩，把大学/研究院/饭店/市场/纽约重新压成履历说明。

5. **结局回收**
   - 1995只回收真正需要回收的关系；
   - 不用最后一顿饭解释所有独立人生。
