# 《没有剧透的中国》叙事规则 V0.1

> 状态：**CURRENT CONTENT BASELINE**
>
> 工作名：**接力式群像叙事**

## 1. 核心结构

不再采用“五部 + 30个历史专题”。

整本书只有一条真正连续的主线：**时间向前。**

人物不是五条互不相干的平行轨道。镜头在同一条时间河流中跟随“此刻最有故事的人”，并通过人物相遇、信件、物件和共同事件把叙事接力给下一个人。

节奏：
**分开 → 分开 → 汇聚 → 再分开 → 关系改变 → 再汇聚。**

## 2. 视角

默认采用**有限第三人称，多人物轮换**。

硬规则：
- 一个完整场景只能进入一个人物的内心。
- 不在同一酒桌/同一连续场景中“跳头”。
- 需要换视角时，优先同时换场景、时间或空间。
- 同一事件可以多视角，但只有当第二视角提供新的意义，而不是重复叙述。

第二人称“你”不再作为正式正文默认叙事方式。第一章旧版第二人称属于 Workflow Demo 的试验结果。

## 3. 切换原则：接力，不轮班

错误：
周启一章 → 周玲一章 → 建军一章 → 小梅一章 → 王东一章，机械平均。

正确：
前一个人的行动自然把某个人、某封信、某件物品或某个未完成的问题递给下一场。

示例：
周启上车离开 → 刘建军站在站台 → 下一场跟随刘建军；
小梅收到周启来信 → 下一场切到省城正在写信的周启；
婚礼中周玲看到小梅和周启 → 下一场换地点后进入小梅视角。

## 4. 两类章节

### 人物推进章
通常70%—90%跟随一个人物，推进其欲望、困境、选择和后果。

### 汇聚章
围绕一个共同事件：1978合影、1985婚礼、1988失败、1990葬礼、1995最后一顿饭等。

汇聚章允许多视角，但仍遵守：
**一个场景 = 一个视角。**

## 5. 群像不是平均主义

五个核心人物都重要，不要求篇幅均分。

当前仅作节奏参考而非配额：
- 周启：偏高
- 林小梅：前期较轻，后期显著增强
- 刘建军：行动性强，承担较多外部事件
- 周玲：家庭与日常生活线的重要承重人物
- 王东：早期较少，后期随着与建军关系升级而增强

人物可以长时间不获得视角。缺席期间可通过信、他人谈论、物件和变化后的重逢继续存在。

## 6. 信息差是叙事动力

允许读者知道A不知道的事情。

例如：
- 读者已经知道小梅停止等待，周启却还认为“等岗位稳定就回去谈”。
- 读者已经知道王东越来越无法忍受建军替自己决定，建军却仍觉得“我不会亏待他”。

不由作者总结“矛盾加深”，而让读者先意识到冲突迟早会发生。

## 7. 历史进入正文的唯一条件

历史不是章节任务。

只有当某个制度、价格、商品、交通条件、政策变化或社会习惯**改变人物的选择、风险、误解或关系**时，才进入故事。

写作检验：
> 删除年份、政策名和历史名词以后，这个故事本身还值得读吗？

如果不值得，说明章节仍在“为讲历史编故事”。

## 8. 正文不默认使用解释层

正式故事正文默认：
- 不设“时代旁注”
- 不设“历史知识卡”
- 不为了证明真实性强插历史照片
- 不突然用统计数字打断人物
- 不由作者频繁解释“这意味着什么”

史实研究继续严格进行，但先服务于作者写对，而不是给读者上课。

历史照片、档案、统计、制度说明等，后续优先进入：
- 书末/章末资料
- 独立档案层
- 电子版主动展开的可选层

是否重新进入正文，需要在完整故事写通以后单独决定。

## 9. 章节视角卡（写作前必填）

每章/场景开始前必须回答：
1. 这一章/场景是谁的？
2. 他现在最想得到什么？
3. 什么阻止他？
4. 结束时发生了什么不可逆变化？
5. 故事接力棒自然交给谁/什么？

如果3、4答不出来，该段很可能只是时代介绍。
如果5答不出来，该段很可能是孤立支线。

## 10. 贯穿物件

当前可反复出现但不得象征化过度：
- 1978五人合影
- 周启与小梅之间的信
- 刘建军修过的收音机/早期物件
- 小梅从纽约寄回的曼哈顿照片
- 周家的旧桌子

物件的作用首先是连接人物和时间，其次才是象征。

## 11. 结局原则

1995不是总结历史，也不是大和解。

刘建军与王东不因一顿饭恢复如初。
周启与周玲的怨气不会一夜消失。
周启与小梅不会突然得到补偿性结局。

结尾只需要让人物开始用新的方式看对方。
