# V5.1 分页器纠偏

本轮针对整章自动分页失败进行了结构性修正，而不是继续单页打补丁：

- 删除正文流全高 `height:100%` 对分页测量的干扰；
- 分页溢出判断改为读取实际正文 / 图片节点的真实底边位置；
- 场景起始页不再可能因为空正文容器而只剩标题；
- 删除会人为制造图片孤页 / 空白页的 `used > .72` 与 `contentAmount > .80` 逻辑；
- 自动清理真正的空白页；
- 图片插入后允许后续正文继续自然环绕；
- 旁注固定在正文版心右下，正文只在旁注真实高度范围内绕排；
- 旁注若需要换页，会携带邻近上下文，而不是漂移到完全不相关的正文旁；
- 旁注与图片的复杂环绕不在同一页强行叠加；
- QA 新增空白页、标题孤页、图片孤页、溢出、异常欠填充检查。

目标：正式第一章重新回到已确认的 `design/layout-lab/` 母版逻辑。

# V5.2 整章截图复核与修复

根据整章实际截图，本轮确认并修复：
- 右下旁注页正文左侧出现大块空白；
- 同页出现两张浮动图，导致正文被压成极窄列；
- 视觉节点强制分页造成正文页严重欠填充；
- “万元户”视觉页只有极少正文；
- 场景末页时代旁注上方/左侧空白过大；
- 美国来信一页大量一句一段，阅读节奏过碎；
- 四种人生复原图文件在浏览器中未正常显示。

分页器改为“延迟视觉节点”：
- 图片/旁注放不下时不立即强制新页，而是等待下一次自然分页；
- 新页优先带入待插入视觉，再继续正文；
- 每页最多一个复杂视觉节点；
- 场景内分页后自动从下一页回填正文，减少异常欠填充；
- 场景结束仍有待插图时，自动携带前页末尾上下文，禁止生成图片孤页。

同时将美国来信段落合并为更自然的对话叙事段。

# V5.3 用户截图复核

本轮针对三个具体问题修复：

1. 第一节两个编辑复原图缺少“同页多配图”规划：
   - 不再作为两个独立 float；
   - 合并为双列 `inline-visual-pair`；
   - 两张图整体参与分页，避免其中一张掉到下一页形成图片孤页。

2. “万元户”旁注正文侵入：
   - 根因是页面整体通过 `transform: scale()` 缩放后，代码使用了 `getBoundingClientRect().height`（缩放后高度）去和 `clientHeight`（未缩放高度）混算；
   - 已改为 `offsetHeight`，并增加 14px 安全避让。

3. 美国来信旁注存在同类轻微侵入：
   - 同步由上述计算修复；
   - QA 增加逐行文字矩形与旁注矩形碰撞检测，后续出现正文侵入会直接报告 `note-text-overlap`。

# V5.6 分页尾页再平衡与 QA 纠偏

本轮基于自动截图逐页复核发现：
- 第 3、6、8、12、16、18、22 页的“underfill”大多是假阳性；
- 原因是 QA 使用 offset 几何计算，无法准确反映 float 图片导致的真实行框位置，并且没有把右下时代旁注占用的区域计入页面使用高度；
- 第 4 页则是真正存在视觉欠填充：第一节结束时双图在右侧，但正文提前结束，页底出现明显大块空白。

修复：
- QA 改为在取消翻页 transform 后统一使用 getBoundingClientRect()；
- 时代旁注底边计入页面已使用区域；
- 正文页欠填充阈值调整为 85px，场景起始页为 125px；
- 分页器新增“场景尾页再平衡”：当场景最后一页明显过空时，从上一页末尾向尾页回流正文，只在两页整体更均衡且不溢出的情况下保留移动；
- 目标不是机械填满，而是避免第 4 页这类肉眼明显不正常的大块空白。

# V5.7 浮动图片真实行框与复杂页保护

自动截图复核进一步发现：
- 第 8 页等页面肉眼已经排到页底，但 QA 仍报告大面积 underfill；
- 原因是段落绕排 float 图片时，块级元素的 getBoundingClientRect() / offset 几何并不等于实际文字行框位置；
- 第 3 页在“尾页再平衡”后又出现左侧正文被抽走、只剩右下旁注的问题。

修复：
- 正文使用 Range.getClientRects() 读取真实文字行框，作为分页与 QA 的可见底边；
- 时代旁注只参与越界 / 碰撞判断，不再用旁注底边冒充“正文已经填满”；
- 含旁注或图片的复杂场景尾页禁止自动抽取 / 回流段落；
- continuation 新页已经放入待排视觉后，如果长段落放不下，优先按句切分并保留视觉，不再为了塞正文把视觉节点踢到下一页；
- 目标是让第一节形成更稳定的“前页视觉栏、后页时代旁注”关系，同时保持左右正文密度正常。
