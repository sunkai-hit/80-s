# V5.1 分页器纠偏

本轮针对整章自动分页失败进行了结构性修正，而不是继续单页打补丁：

- 删除正文流全高 `height:100%` 对分页测量的干扰；
- 分页溢出判断改为读取实际正文 / 图片节点的真实底边位置；
- 场景起始页不再可能因为空正文容器而只剩标题；
- 删除会人为制造图片孤页 / 空白页的 `used > .72` 与 `contentAmount > .80` 逻辑；
- 自动清理真正的空白页；
- 图片插入后允许后续正文继续自然环绕；
- 旁注固定在正文版心右下，正文只在旁注真实高度范围内绕排；
- 旁注若需要换页，会携带邻近上下文，而不是漂移到完全不相关的正文旁；
- 旁注与图片的复杂环绕不在同一页强行叠加；
- QA 新增空白页、标题孤页、图片孤页、溢出、异常欠填充检查。

目标：正式第一章重新回到已确认的 `design/layout-lab/` 母版逻辑。

# V5.2 整章截图复核与修复

根据整章实际截图，本轮确认并修复：
- 右下旁注页正文左侧出现大块空白；
- 同页出现两张浮动图，导致正文被压成极窄列；
- 视觉节点强制分页造成正文页严重欠填充；
- “万元户”视觉页只有极少正文；
- 场景末页时代旁注上方/左侧空白过大；
- 美国来信一页大量一句一段，阅读节奏过碎；
- 四种人生复原图文件在浏览器中未正常显示。

分页器改为“延迟视觉节点”：
- 图片/旁注放不下时不立即强制新页，而是等待下一次自然分页；
- 新页优先带入待插入视觉，再继续正文；
- 每页最多一个复杂视觉节点；
- 场景内分页后自动从下一页回填正文，减少异常欠填充；
- 场景结束仍有待插图时，自动携带前页末尾上下文，禁止生成图片孤页。

同时将美国来信段落合并为更自然的对话叙事段。
