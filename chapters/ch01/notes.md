# 第一章工作笔记（Workflow Demo）

> 状态：**WORKFLOW DEMO / NON-CANON**
>
> 本章《如果你在1985年二十岁》不再属于正式出版故事基线。
>
> 它的价值是：跑通文字、考据、视觉、本地化、分页、HTML、QA工作流，并帮助项目发现旧方法的核心问题——历史元素过多，陌生读者缺少可持续追随的人物和故事。

## 旧实验结构
1. 星期六早上七点
2. 建军的新自行车
3. 小梅穿了一条红裙子
4. 晚上九点，宿舍里有人听歌，有人读尼采
5. 父亲觉得你们这一代人很奇怪
6. 夜里十一点，你面前摆着四种人生

## 为什么退出正式正文
- 复合型第二人称人物难以形成长期人物弧光；
- 章节由历史元素推动，人物更像时代主题载体；
- 单章塞入单位、分配、个体经营、流行文化、出国等过多元素；
- “过来人”容易靠记忆补足背景，陌生读者缺乏持续故事动力；
- 时代旁注/历史照片等机制容易打断人物叙事。

## 仍然保留的成果
- Web Book单页数字书技术；
- 分页器与共享CSS/JS；
- 图片本地化与版权记录方式；
- DOM / screenshot视觉QA；
- 版式回归经验；
- `review.md` 中的失败案例和排版修正记录。
