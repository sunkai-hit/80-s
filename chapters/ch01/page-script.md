# 第一章页面脚本 V2.0

> 阅读形态：单页数字书 + 杂志型插页  
> 原则：一屏一页；正文页不滚动；翻页阅读；视觉页和时代翻译页独立存在。

## 视觉基线

- 桌面端：单页书册，页面比例约 0.76（接近常规图书页）
- 页面中央有明确纸张边界、阴影、页码和页眉
- 每页内容必须在一屏内完整显示
- 正文页不插大图
- 图片、史料、时代翻译分别占独立页或图文页
- 所有复杂视觉均为独立图片/SVG/WebP资产，不由HTML绘制

# 翻页交互

桌面端：
- 鼠标滚轮：一次滚轮切换一页
- ← / →：前后翻页
- PageUp / PageDown：前后翻页
- 空格：下一页
- Home / End：首尾页

移动端：
- 左右滑动翻页
- 页面自适应宽度
- 不在页内纵向滚动

# 页级组件

1. text-page：纯正文页
2. translation-page：时代翻译页
3. image-page：时代影像页
4. split-page：图文页
5. object-page：实物史料页
6. closing-page：视觉/章节收束页

# 强约束

- 不允许把大图塞进正文段落中间
- 不允许时代翻译与正文无边界混排
- 不允许复杂视觉用HTML/CSS绘制
- 不允许任何页面需要纵向滚动才能看完
- 不允许为了“装饰”增加无意义图片
