# 第一章页面脚本 V2.2（最终执行版）

> 阅读形态：**单页数字书 + 杂志型插页**  
> 当前实现：**33页**  
> 页面文件：web/ch01/index.html

## 阅读规则

- 一屏只显示一张书页，页内禁止纵向滚动。
- 桌面端：滚轮、←/→、PageUp/PageDown、空格翻页。
- 移动端：左右滑动翻页。
- 每页有明确纸张边界、页眉、页码和外部阅读背景。
- 正文页不插大图。
- 时代翻译、照片、实物、编辑视觉独立成页。
- 复杂视觉是独立图片/SVG资产，不由HTML/CSS直接画。
- HTML只负责书页排版、文字、图片摆放和轻量交互。

## 工程

- CSS：web/shared/css/book.css
- JS：web/shared/js/book.js
- 设计页尺寸：820 × 1080
- 页面整体随浏览器视口缩放，保持书页比例。
- JS会检测正文页实际可用高度；如果系统字体差异造成溢出，会逐步小幅降低该页字号。
- 翻页只有轻微水平位移，不使用3D翻书动画。

## 强约束

- 不允许大图插进正文段落。
- 不允许时代翻译和正文混为一个连续块。
- 不允许用HTML的圆、框、箭头拼复杂视觉图。
- 不允许单页内部继续纵向滚动。
- 不为了“看起来丰富”强行增加AI图片。
- 历史照片必须注明年份、来源、权利状态，并说明是否为故事现场。

# V3.0 标题与视觉规则

## 标题规则
不再“每页一个标题”。

正文中只在真正换场景时显示大标题：
- 星期六早上七点
- 建军的新自行车
- 小梅穿了一条红裙子
- 晚上九点，宿舍里有人听歌，有人读尼采
- 父亲觉得你们这一代人很奇怪
- 夜里十一点，你面前摆着四种人生

同一场景中的后续分页：
- 不显示正文小标题；
- 只保留页眉中的场景名称；
- 正文从正常书页上缘直接开始。

## 视觉规则
P04 / P06 / P12 / P29 已全部改用 image2 编辑视觉，并存放在 `assets/ch01/generated/`。
复杂视觉不再使用 SVG/HTML 程序式绘制。
正式采用的历史照片全部存放在 `assets/ch01/historical/`，HTML 不使用远程图片热链。

# V4.0 排版收口（当前有效）

当前正式页面从33页调整为 **31页**。

本轮原则：
- 正文分页按阅读密度独立处理，不再为了和“时代翻译/时代影像”一一对应而强行断页；
- 将“建军的新自行车”原高密度页拆开；
- 合并“一万元”前后的短页；
- 合并宿舍段落中的短页，让连续阅读更自然；
- 正文小标题整体下移，连续页继续隐藏重复标题；
- “时代翻译 / 时代影像 / 时代证据 / 编辑视觉”不再使用整页大图模式，统一改为正常出版物常见的 **文字 + 旁插图** 版式；
- 视觉页与正文页使用同一纸张背景，降低“突然进入插页”的割裂感；
- “四件东西，四条路”使用新的无标签视觉，去掉“你还没有选。”及“单位稳定”等四个小标签。
