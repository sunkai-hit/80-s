# 第一章 Page Script V5.0｜纪实小说母版

状态：**CURRENT**

正式页面：`web/ch01/index.html`

## 1. 排版方式

本章已从旧的“正文页 + 独立时代XX页”切换为全书统一的 **纪实小说母版**：

- 扉页；
- 场景起始页；
- 普通连续正文页；
- 正文 + 右下时代旁注；
- 正文 + 历史照片；
- 正文 + 编辑插图。

不再存在独立的“时代翻译页 / 时代影像页 / 时代证据页 / 时代尺度页”。

## 2. 分页

正式 HTML 不再手工写死每页字数，而是使用：

`web/shared/js/chapter-paginator.js`

基于固定 820 × 1080 逻辑书页和真实浏览器渲染高度分页。

规则：
- 普通正文页从统一首行线排到统一末行区域；
- 下一整段放不下时，优先按自然句界拆分长段落；
- 场景开始使用标题下沉母版；
- 视觉节点不强迫正文提前断页；
- 旁注上方正文保持通栏，只在旁注真实高度范围内绕排。

因此页码由当前文字、字体与视觉节点自动生成，不再把“P04 / P12”之类人工页码当作内容结构的一部分。
