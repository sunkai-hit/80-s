# 第一章历史考据清单 V0.1

> 原则：本文件记录需要核验的历史事实、数据与史料来源。  
> 不要为了“显得有研究”而把所有数据塞进正文。

## A. 必须核验：影响人物选择

### 1. 高校毕业分配制度
需要确认：
- 1985年前后高校毕业生分配制度的典型流程
- “国家包分配”作为通俗表达的准确边界
- 个人志愿、学校、地方和用人单位之间的实际关系
- 可展示的真实派遣/报到材料样本

状态：待系统核验

### 2. 城市“单位”体系
需要确认：
- 大型国企典型福利范围
- 职工医疗、食堂、托幼、住房的典型形态
- 避免写成所有单位都完全相同

状态：待系统核验

### 3. 待业青年 / 个体户
需要确认：
- 1980—1985城市待业青年就业压力
- 个体经营政策变化
- 个体户在社会评价上的真实史料
- 广州服装流通、南下进货的典型材料

状态：待系统核验

### 4. 万元户
需要确认：
- 1985全国职工平均年工资
- “万元户”的媒体语境与典型行业
- 不简单折算成今天人民币

状态：初步已知，正式出版前需要权威来源定稿

### 5. 自费留学 / TOEFL
需要确认：
- TOEFL在中国开考时间
- 1985年前后个人申请、自费留学的政策环境
- 美国留学生打工的实际限制与典型经历
- 海外来信在当时的信息传播作用

状态：待系统核验

## B. 用于时代感，可视情况核验

- 双卡录音机在1985年的普及程度
- 邓丽君磁带的民间翻录传播
- 红裙子、牛仔服、喇叭裤在1985城市青年中的出现
- 夜大学/成人教育的典型形式
- 电影院与公园作为青年约会空间
- 多人大学宿舍的典型人数与家具

## C. 正文中不急于加入的数字

除非影响人物理解，否则不主动加入：

- 全国宏观GDP
- 大量政策年份
- 过多电器百户拥有量
- 一整套物价表

## D. 史料标准

正式引用优先级：

1. 国家统计局 / 教育部 / 法规文件 / 档案馆
2. 当时报纸杂志
3. 高校校史 / 地方志 / 博物馆
4. 高质量口述史、回忆录
5. 学术研究

影视剧、小说只用于研究“社会想象”，不直接作为事实证据。
