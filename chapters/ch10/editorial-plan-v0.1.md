# 第十章《远路》逐章故事编辑方案 V0.1

> 状态：**EDITORIAL APPROVED（2026-09-28 作者明确选择 A2＋B2）**；广州第一天为重点，主要跟随刘建军，王东仅在实际独立办事时短暂获得视角。此文件是写作前编辑依据，不是正文。
> 依据：`book/editorial-plan-ch08-ch11-v0.1.md`、第9章V1.3、原第10章V1.0与节奏实验V1.1、原34章双暗线地图。

## 1. 已锁定的故事与阅读目标

1984—1985前后，建军与王东第一次去广州寻找更远的供货渠道。广州、火车、旅社、各地客商是他们眼前的生活，不是历史资料展示。两人亲历更大的生意世界后，王东靠实际本领逐步取得货物核验、托运和下一趟路线筹划的责任；何老板是有自己生意的人，自然记住经办人“王东”。建军有眼光、敢打交道，并非总是王东的反面教材。婚礼上那句“跟着我干的”仍应是当时正常说法，1992年的裂痕不提前排练。

**已确认的叙事方向**：这趟远行本身要有趣，而不是逐项过一遍采购步骤。第9章小卢已来摊位短期帮忙；本章只写出发前如何交代工作，不重演首次请工。

## 2. 候选场面如何取舍

| 内容 | 编辑考虑 |
|---|---|
| 江城出发 | 用一件摊位真缺货的事说明为什么非得亲自去；小卢留守只需顺带交代。父亲、地图、行李等只选好看的生活材料。 |
| 火车上 | 选一段能看出建军、王东性格差异的陌生人交往；允许纯趣味，不硬给它设置采购回报。 |
| 广州初见市场 | 两人看见相同商品的巨大选择，价格并非唯一尺度；体验差别来自他们不同的注意力，不写导游式商品目录。 |
| 何老板与第一次交易 | 何老板考虑自己的仓储和客商，不负责赞赏主角；双方看货和谈价可以好玩，但不连续安排三四道人工关卡。 |
| 王东独立办理实际事务 | 建军明确分出一个合理权限，王东真正做成事，何老板随后自然喊出他的名字；不安排越权后瞬间原谅的戏。 |
| 回江城 | 货与人可能不同时回来；畅销与滞销可各出现一例。建军请王东列下一次路线，以一项实务变化结束。 |

## 3. 本章需要选择的两项具体编排

**选择A：这一趟最值得完整呈现的记忆点**
- **A1 车厢里的陌生人**：旅途中两个人遇到一个有趣但不一定带来生意的人；到广州以后才进入较紧凑的市场及交易主线。
- **A2 广州第一天**：火车上只留好看的片段，重点完整写初见市场、找货和初识何老板的一天；陌生城市对两人的不同刺激成为记忆点。
- **A3 旅社的一晚**：出发与初见市场写得利落，完整写一天奔走后两人在旅社休息、闲聊和算账的夜晚；把另一面生活留给读者。此方案必须让夜晚本身有趣，不能变成财务讨论纪录。

**选择B：主视角的自然移交**
- **B1 建军带读者出门，遇见何老板后自然转入王东**；王东下半段独立办事成为情节顺势接力。（编辑初选）
- **B2 建军走完全程，王东只在确实独立执行的阶段获得一次短暂完整视角**；更突出建军初看广阔世界的兴奋。
- **B3 开篇从王东切入，直到一段建军更有趣的谈生意场面才转入建军**；把王东看起来沉静却有好奇心的一面先写出来。

这些是关于叙述镜头与完整展开哪一幕的选择，不是必须制造什么固定冲突。其余场面仍按实际故事需要伸缩。

## 3A. 作者确认结果与具体写法（本节覆盖第三节候选项）

作者明确选择：**A2 广州第一天＋B2 主要跟随建军，王东只在独立执行时获得短暂、完整视角**；无补充要求。

- 出发：摊上熟客缺的真实货品，引出建军主动去广州；第九章出现的小卢按天帮忙已是事实，不再招聘第二次；王东的记账本用来帮助约束买什么，建军仍主导目的、业务关系和出资。
- 火车：留下一个值得记住的短片段，展示两个人既是熟人又各有注意力，不借旅客之口背政策或强行埋伏笔。
- **广州第一天获得全章最充足的具体描写**：两人在陌生街道寻找货源，看到商品和做生意方式的差别；何老板首先是正在工作的本地商人，他们通过有来有往的交谈与货物体验逐渐熟悉，而不是一见面就通过三道测验。
- 第一笔采购：建军能捕捉新货机会，王东凭熟客需要识别某种不合适的规格；不是由一个人持续犯错、另一个人持续纠错。决定权和金额归建军，包装、核对和在已议定范围内的发运安排由建军明确托付王东。
- **仅当王东独自去办已经授权的货物点数、单据或托运时，分离场景并短暂切入王东视角**。他实际做了什么，比供货商夸奖更有分量；何老板经过几次共同办事后自然记住并叫出王东的名字。建军仍是全章主视角，回城后继续跟随他的实际销售与新想法。
- 回江城：货物卖得有快有慢，下一趟由王东先排出地点和货单供建军查看；这一变化同时让两个人高兴，不提前编排后来决裂的怨恨。

**取舍提醒**：不为模仿第九章加入平行的家庭戏，也不为“广州第一天”强造丢包、被骗、逐家扑空等连续障碍。旅社可仅保留当晚具体生活感，最终篇幅依场面是否真正有趣灵活调整。

## 4. 双暗线（作者后台）

- **人生**：王东开始在供货商面前被直接叫名字，渐有可独立承担的工作；建军仍自然认为机会来自自己带路。此时他们是愉快可信的伙伴，不做预言式怨怼。
- **时代**：铁路远途、旅社住宿、市场货源差别、纸质联系人地址、包装与托运以及不便即时沟通，应以人物实际要做的事呈现。不靠年份词或稀奇道具摆设“年代感”。
- **留白**：不必在本章交代当时广州商业全貌，也不把1988坏货危机提前模拟一次。

## 5. 历史核验前置风险

1983年国务院补充规定对经批准的长途贩运、批量销售设有商品范围与经营许可边界，不能据此推定任何电子零件和批量规模均可自由买卖。正式写作前应结合本章最终选定的具体货品、数量和流转方式核对；铁路托运单、实际交通时程亦在必要时查证。虚构角色不借后世术语讨论当时制度。
