## 六张样页

1. 扉页：验证《如果你在1985年二十岁》单行排版。
2. 场景起始页：验证小说章节式“标题下沉”。
3. 普通连续正文页：验证标准文字密度。
4. 正文 + 时代旁注：验证“时代翻译不单独成页”。
5. 正文 + 史料照片：验证真实历史照片直接长在叙事里。
6. 正文 + 编辑插图：验证 image2 / 场景复原作为正文插图，而不是独立视觉页。
