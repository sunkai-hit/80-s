## 第二轮反馈形成的版式规则

### 正文页的核心不是“留白”，而是稳定版心
- 除扉页、场景真正结束页、章节真正结束页外，普通正文页都使用固定首行线与固定末行线。
- 正文不得因为视觉内容、时代旁注或人为分页而在顶部或底部留下大块空白。
- 普通连续正文页从统一首行线直接开始。
- 场景起始页只允许在“场景标题 → 正文第一行”之间保留有意留白。
- 正文最后一行应尽量落到统一末行区域，而不是随每页内容多少上下漂移。

### 旁注
- 旁注栏本身可以在上方留白；
- 旁注内容默认贴栏底，从底部向上生长；
- 同页多个旁注时，从底部向上依次叠放；
- 不在正文中部悬浮一个孤立的说明块。

### 图片
- 历史照片与编辑插图均嵌入正文版心；
- 图片存在不改变正文首行线、末行线规则；
- 图片不应成为制造正文大块留白的理由。

### 重点词
- 行内重点词加粗时，与前后文字保留轻微字间呼吸；
- 不采用“粗体词和后文紧贴”的排法。

本轮仍为样张验证，不回写正式第一章和全书最终工作流。

## 第三轮样张修订

- 场景起始页：标题下方留白增大到与标题上方的视觉留白接近；通过继续排入后续正文，正文仍落到统一末行区域。
- 连续正文页：同步顺延文字，保持叙事连续与固定首末行。
- 时代旁注页：改为“上半页通栏正文 + 下半页双栏”的结构。
- 横线以上不再为了旁注预留右侧空白。
- 右侧旁注只占页面下部，并与左侧下部正文共同受末行边界约束，避免被页脚遮挡。
- 本轮仍只修改 `design/layout-lab/`，正式第一章保持冻结。
