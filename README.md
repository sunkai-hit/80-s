> 历史后来有答案，生活在历史中的人没有。

本仓库用于《没有剧透的中国》第一册（1978—1995）的故事策划、历史考据、正文、Web Book 与出版资产管理。

## 当前创作方向

项目已从早期的“历史专题 + 体验式章节”转向：

**人物驱动的接力式群像叙事。**

1978年，周启、周玲、刘建军、林小梅、王东仍生活在同一个小型关系网络里。之后十七年，他们不断分开、交叉、帮助、亏欠、误解和重新理解彼此。1995年，周家搬离老家属院，几个人因“最后一顿饭”重新回到最初的地方。

不再预设“五部30章”，也不按历史主题给人物分任务。

## 核心写作原则

- 先有人，再有人生；先有人生，再有时代。
- 人物不是历史主题的代言人。
- 正文首先必须作为故事成立。
- 历史只在改变人物选择和关系时进入正文。
- 默认有限第三人称；一个完整场景只进入一个人物内心。
- 采用“接力式群像”：前一场自然把故事交给下一人物，而非机械轮班。
- 正文默认不使用时代旁注、历史知识卡和强插历史照片。
- 史实研究继续严格进行，但主要作为作者后台的真实性约束。
