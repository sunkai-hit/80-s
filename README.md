## 核心写作原则

- 先有人，再有人生；先有人生，再有时代。
- 人物不是历史主题的代言人。
- 正文首先必须作为故事成立。
- 历史只在改变人物选择和关系时进入正文。
- 默认有限第三人称；一个完整场景只进入一个人物内心。
- 采用“接力式群像”：前一场自然把故事交给下一人物，而非机械轮班。
- 正文默认不使用时代旁注、历史知识卡和强插历史照片。
- 史实研究继续严格进行，但主要作为作者后台的真实性约束。
